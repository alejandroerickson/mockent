# Charter

## What it is

- A **public** repository, `alejandroerickson/mockent` (MIT), holding one mock
  enterprise application, **ADIT**
  ([decision](../decisions/product-is-adit-invented-mining-exploration-ems.md),
  [the mock world](../domain/adit-mock-world.md)), and the records that let
  an assistant pick it up cold: `AGENTS.md`, this bundle, and the design
  records.
- Designed in a data-ops console design system recorded in `DESIGN.md`
  ([decision](../decisions/design-system.md)).
- Published at `https://alejandroerickson.com/mockent/`
  ([decision](../decisions/one-pages-site-from-actions.md)).

## What it is not

- Not a place for real enterprise data. Every company, person, place, assay,
  price and budget in the app is invented.
- Not a place for session memory. The repository is public, so logs,
  requests and handoff notes are kept privately, outside it.
